# 車両の影が後描きレールを隠す問題

2026-10-25、15:47のスクリーンショットを受けて追加調査した。前回の自動除外削除と車体内のパス統一だけでは、地形と車両の間の描画順は直っていなかった。

## 原因と修正

RailDrawQueueはAFTER_BLOCK_ENTITIESでレールVBOを提出する。スクリプト付き車両は半透明パスをその後に提出するが、スクリプトのない車両はその場で影を描いていた。影は本家どおり深度を書き込むため、その後に描くレールが深度テストに落ちる。

スクリプトのない車両の半透明パスも同じフレームのレール提出後まで保持する。全体の不透明パスは従来の位置に残す。半透明の深度書き込みや影メッシュ・テクスチャのアルファ値は変更しない。

保持するものはローカルpose・法線行列、グローバルModelView、スクリプト描画状態、平行光源、室内灯。LocalSpaceBatchでは車両位置がグローバルModelViewに入るため、poseだけのコピーでは不十分。再生時には保持した状態でバッファをflushしてから元の状態へ戻す。GUIプレビューは即時描画を続ける。シェーダーパック使用時は既存のスクリプト付き車両と同じく遅延対象外で、この構成での解消は確認していない。
