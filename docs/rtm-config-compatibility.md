# RTM設定・分岐・透明度の照合記録

## 修正と検証

- 標準分岐の `LibRenderRail.js` から `getBrightness` を呼ぶと、`(Level,int,int,int)` と `(Object,double,double,double)` の選択がNashornで曖昧になることを再現した。公開シグネチャを一本化し、本家の整数座標への変換と明るさ取得を維持した。
- 標準レールの可動部を独自キャッシュから外した。本家と同じく静的部分だけを保持し、動的コールバックは毎フレーム実行する。スクリプトが空の描画を返しても、別のレール形状に差し替えない。
- 標準・HPの両スクリプトを実行し、左／右、正方向／逆方向、転てつ0／0.5／1の24組でレール・トングの描画命令と状態変化を検査した。これは実スクリプトの検査であり、ゲーム画面での確認とは区別する。
- 旧OpenGLの固定精度アルファテストに合わせ、通常描画とIris用マスクの透明度を8ビット正規化精度で比較するよう変更した。小数の完全一致判定による不透明面の欠けを防ぐ。旧仕様は[OpenGL 1.4仕様書 4.1.4](https://registry.khronos.org/OpenGL/specs/gl/glspec14.pdf)参照。
- 実GPUのFBOで、1直前・1・1直後の透明度を使った768ピクセルを検査した。既存の通常／Iris用描画の透明度・深度160検査も通過した。報告者のWindows/GPU環境で同じ症状が解消するかは未確認。

## ファイルと設定画面

本家KaizPatchX `RTMConfig.syncConfig` の全24項目を、カテゴリ・キー・既定値・許容範囲を合わせて定義した。両ローダーで同じ定義を共有する。

- NeoForge: 主設定ファイルは `config/RTM.cfg`。毎回の起動時にこのファイルを優先して読み、編集値を反映する。MOD一覧の設定画面を使用した場合も `RTM.cfg` に保存する。NeoForgeが生成するTOMLは設定画面用のミラー。初回にRTM.cfgが存在しなければ既存のTOMLから引き継ぐ。
- Fabric: `config/RTM.cfg` を起動時に読み書きする。本家の `B:` / `I:` / `D:` 形式。変更は再起動後に反映。未知の項目とコメントは保持し、欠けた項目を補完、不正値を既定値に修正する。Fabricのゲーム内設定画面は未実装。
- 列車・銃の音量は0～100の設定値を0～1に変換する。
- 実サーバー上で24項目すべてについて、RTM.cfg・設定画面・互換APIのフィールドが一致することを検査した。既存TOMLと異なるRTM.cfgを使い、RTM.cfg側が優先されることも確認した。生成ファイルの往復、設定値の変更、不正値・上限・下限も検査した。

## 未確認事項

- 報告者の車両・GPU・MOD構成での最終表示。点状になる経路に関係する透明度の実装差は修正・GPU検査済みだが、同じ環境を再現した検証ではない。
- スクリーンショットの分岐をゲーム画面で最終確認すること。実スクリプトの動的描画検査は通過している。
- ミラーは通常描画・Fabulous・Iris使用時の実ワールド検査済み。256／512／2048のGPUバッファ作成・読戻し・解放、6方向の反射・投影・UV、設定変更による解像度更新を確認。Irisでは専用の描画先・パイプラインを使い、通常描画の空と反射物体を深度・色で合成する。静的な鏡面テクスチャへの一律切替は撤去した。任意のシェーダーパックの独自ポストエフェクトまで一致することは未検証。
- サーバーパックは実接続でマニフェスト・分割送信・SHA-256検証・有効化まで検査。既定は無効。ファイル数128、単体128MiB、合計512MiBの上限。元の無制限な転送とは異なる。
- 音声ペイロードに距離を追加したため、サーバー・クライアント双方のJARを同じ版に更新する必要がある。
- 上記4機能の未接続部分を追加済み。Minecraftの世代差、任意の外部パック・GPU・描画MODの組み合わせを含む完全互換と断定する検証ではない。

## 追加検証

- NeoForgeの実サーバーで10テスト通過（設定24項目、SRBX操作、E259姿勢、3段階の読込結果・順序一致、マーカー状態・建築限界の通信と保存）。
- NeoForgeの隔離クライアントでサーバーパック配信とミラー描画を実行。設定再読込ループなし、鏡のテクスチャ欠落なし。
- `Use like 1.12` はRTM.cfgでは原名を維持する。NeoForge設定画面の内部TOMLだけはドット解釈を避け `Use like 1_12` とする。
- NeoForge/Fabricで設定・音距離・キャッシュ・転送・反射座標・並列登録順・更新用HTTP通信の回帰検査通過。両ローダーの実クライアントで通常描画とIrisの鏡像、サーバーパック配信を検査した。Iris 1.8.14-beta.1／Sodium 0.8.13／Complementary Reimagined r5.9.3を使用。

- NeoForgeの実画面で6ボタンすべてをレイで選択・クリックし、サーバーへの状態同期と保存を確認した。
- 実GPUで鏡の空・黒い不透明物体・有色物体を合成し、黒い物体を空として消さないことと深度マスクの復元を確認した。
- Fabricでは非対称視野によるFrustum調整ループの停止不能と、Irisの描画状態が入れ子の描画で失われる問題を修正・実起動検証した。
- ミラー用の通常描画をシェーダーのON/OFF変更として扱わず、全モデルのキャッシュ再構築を起こさないことを回帰検査した。
